# Shor's Algorithm explained with Python Simulations

## About 

(c) jfyo2 March 2023

Click on the file "shor_algorithm.ipynb" above to begin. 

Abstract: This notebook provides an in-depth explanation and Python simulation of Shor's Algorithm for factoring numbers. It covers the classical and quantum parts of the algorithm, discusses its limitations and proofs, and uses Python simulation to illustrate the underlying quantum computing, including qubit superposition, quantum wavefunction collapse, and the Quantum Fourier Transform.

Prerequisite math knowledge: Only basic number theory (modular arithmetic, divisibility) and very basic linear algebra/matrices is required. Some knowledge of Fourier transforms might be useful but not required. 
I wrote this as a first-year math undergraduate, so very little specialized math knowledge is required. 

## Building

No build step is required -- this is a single Jupyter notebook.

### Prerequisites
- Python 3.8+
- Jupyter Notebook or JupyterLab

### Setup
1. Clone the repository:
```bash
   git clone https://github.com/username/repo.git
   cd repo
```
2. Install the required libraries:
```bash
   pip install numpy matplotlib sympy
```
   (`random` and `time` are part of the Python standard library and don't need installing.)
   
3. Launch Jupyter and open the notebook:
```bash
   jupyter notebook notebook_name.ipynb
```
4. Run all cells (Cell → Run All, or Shift+Enter through each cell).
