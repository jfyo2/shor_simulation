Abstract: This notebook provides an in-depth explanation and Python simulation of Shor's Algorithm for factoring numbers. Prerequisite math knowledge: Only basic number theory (modular arithmetic, divisibility) and very basic linear algebra/matrices is required. Some knowledge of Fourier transforms might be useful but not required.
